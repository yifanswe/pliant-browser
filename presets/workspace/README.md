# Workspace preset

**Responsibility:** become the primary workspace-oriented reference browser,
using public UI, operation, task, and plugin contracts.

**Boundary:** the preset owns presentation and workspace policy only. It gets no
private access to core, Chromium, platform internals, credentials, or recovery state.

**Status:** scaffold only; no layout, package, or browser output exists. See the
[module map](../../MODULES.md).
